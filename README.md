# 관계·일상 자가점검 (교내 캠페인)

교육·인식 개선용 자가점검 사이트입니다. **의학적 진단이나 공식 고립·은둔 판정이 아닙니다.**

## 로컬에서 열기

`index.html`을 브라우저로 열면 됩니다. (인터넷 없이도 동작)

또는:

```bash
npx --yes serve .
```

## 구성

| 파일 | 역할 |
|------|------|
| `index.html` | 인트로 → 질문 → 결과 → 지원 안내 |
| `app.js` | 9문항 · 채점 · 안전/주의/경고 메시지 |
| `style.css` | 모바일 우선 스타일 |

- 답변은 **브라우저에서만** 합산되며 서버에 저장되지 않습니다.
- 결과 구간(예시): 안전 0–8 / 주의 9–17 / 경고 18–27 (문항당 0–3점)
